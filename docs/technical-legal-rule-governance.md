# Technical legal-rule governance

MECORRESPONDE keeps technical execution and professional legal approval as separate states.

- `technical_draft` may be executed only in `SYNTHETIC` cases so the product can be built and tested end to end.
- `approved` is not sufficient by itself: professional approval also requires non-empty reviewer attribution.
- Any non-synthetic case fails closed unless the rule has attributed professional approval or the exact current case output has passed its existing attributed professional release review. That case-level approval is bound to the current facts, decision and action and does not approve the rule globally.
- Public SEO pages only cite professionally approved rules.
- Internal readiness reports technical catalog completeness separately from professional approval. A complete synthetic catalog does not make the product ready for real data.

This control changes no substantive rule, deadline, remedy, probability, or legal interpretation. `LEGAL_APPROVAL` remains `PENDING`, and `REAL_BETA` remains closed.
